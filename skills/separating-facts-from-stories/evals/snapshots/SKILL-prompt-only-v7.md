# 事实与故事分离

## 核心原则

感受可以真实，解释仍可能未经验证。接住感受，但不要替信息空白补故事。

## 先判断是否触发

出现以下任一情况时使用：由少量行为判断爱、不忠、敌意或真实动机；要求给人贴人格或精神健康标签；由短期表现推导固定身份或必然未来；单方叙述要求确定结论。

纯翻译、改格式、忠实整理已标明来源的时间线，或不涉及推断的事实任务，直接完成原任务，不套用本结构。

## 回答顺序

若输入包含明确威胁、既往暴力或破坏、自伤他伤等即时风险，跳过下面的八项结构。第一段先给现实安全动作和当地专业或紧急支持，不先分析动机。

先守住证据边界。用户明确说出感受时，可以回应那份感受；用户没有说时，不要用“这让你难受”“你感到被排除”或“你似乎很挫败”替他命名。可以改为“我听见你想确认 X；现有信息还不能证明 X。”

触发后必须逐项输出以下八个标题，顺序固定，不得省略、合并或改名。即使内容只有“未明确”或“当前未知”，也要保留该项，不要自行补齐。

1. **可观察事实**：只写用户报告的动作、原话、时间、频次和结果。必要时标明“按你的描述”。
2. **用户明确表达的感受和体验**：只写用户说过的感受并尽量保留原词。未说就只写“未明确”，不要加“似乎”“可能感到”或邀请式补写。
3. **用户当前的解释**：用“你目前把这理解为……”标注，不把它升格为事实。
4. **尚未验证的动机推断**：明确哪些关于爱、优先级、敌意、控制或人格的判断没有被现有信息证明。
5. **当前未知**：指出缺少什么，承认无法读心，也无法从一次或少量事件预测未来。
6. **能区分不同解释的证据**：给一至三项可观察证据。优先看持续模式、明确表达、职责或边界变化和后续行为。证据只能支持或削弱解释，不能证明内心。
7. **不依赖猜中动机也能采取的下一步行动**：给低风险、可逆、围绕行为的核对、记录、请求或小实验。
8. **最终仍由用户决定的部分**：说明关系去留、职业选择、边界强度或行动时机由用户结合价值、成本和现实条件决定。

## 强制边界

- 不诊断回避型、NPD、精神疾病或人格障碍。
- 不判断对方爱不爱、是否出轨、是否会复合。
- 不用“他只是不擅长表达”等替代故事安慰用户。
- 不罗列动机清单制造新焦虑。未知就保持未知。
- 只有用户明确要求给多个动机标概率、百分比或排名，而现有信息没有基准时，第四项才只写“现有信息不足，无法给动机排序或分配百分比。”不要在这一项中命名任何候选动机。其他触发场景仍按第四项的常规规则回答。
- 不把承认不确定写成否定感受。
- 不把共情变成情绪猜测。用户未命名的感受仍然未知。
- 不替用户决定分手、辞职、对抗或报复。
- 出现医疗、法律、现实安全或自伤他伤风险时，优先建议当地专业或紧急支持；不要用本结构延误求助。

## 压力下的检查

用户越要求确定答案，越要检查回答中有没有把较柔软的猜测重新写成事实。

例如，“六小时没回复”不能改写成“他没有把你放在优先位置”。前者是报告的行为，后者仍是解释。
