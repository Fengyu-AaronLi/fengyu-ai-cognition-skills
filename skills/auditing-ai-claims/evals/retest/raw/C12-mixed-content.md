# AI 主张审计

核验日期：2026-08-05

审计范围：只审计后半段关于 OpenAI API 模型、价格与使用成本的四条可核验子句。“夜里的城市像一块还没冷却的芯片”“注意力在风里漏电”属于文学隐喻，不作真假审计。

快速结论：`gpt-5-nano` 这个模型名及每百万输入 token 0.05 美元的官方标价可以确认；“它是 OpenAI 当前最便宜的 API 文本模型”因“文本模型”和价格口径未定义，只能停在当前未知；“所以任何人都能零成本使用”被官方非零价格和不支持 Free 层直接反驳。

## C1 当前 OpenAI 最便宜的 API 文本模型

- 主张类型：数字与比较
- 时效性：高
- 关键结论词与判定条件：“当前”以 2026-08-05 为准；“最便宜”缺少完整判准，至少要限定是否只比较通用文本生成模型、是否排除嵌入与审核模型，以及比较标准输入、缓存输入、批处理还是包含输出的总成本。
- 原始来源：[Pricing | OpenAI API](https://developers.openai.com/api/docs/pricing)、[All models | OpenAI API](https://developers.openai.com/api/docs/models/all)、[GPT-5 nano Model | OpenAI API](https://developers.openai.com/api/docs/models/gpt-5-nano)
- 来源层级：A2 主体自述
- 证据角色：主体自述
- 来源日期：页面未标注统一发布日期；访问核验于 2026-08-05
- 是否实际打开：是；三个链接均成功打开并停留在所列最终 URL
- 来源身份门：匹配，均为 OpenAI 官方开发者文档
- 是否直接支持：部分；模型页只称其为 GPT-5 系列中最快、最便宜的版本，没有直接宣称它在所有 OpenAI API 文本相关模型中绝对最便宜
- 内容支持门：部分
- 支持范围：官方直接 API 的公开模型目录和公开 token 价格；不涵盖第三方转售、云厂商价格、促销额度、缓存与批处理口径，也不能自动把嵌入、审核等不同用途模型纳入同一比较
- 推断跨度：2；从“GPT-5 系列最便宜”跨到“OpenAI 全部 API 文本模型最便宜”，需要额外定义范围并完成全量同口径比较
- 行动适用门：不足以支持仅凭“最便宜”选型；还需比较输出价、工具费、性能和任务适配
- 可反驳观察：在明确口径后，若发现另一个当前可用且同类的模型有更低价格，主张不成立；若官方发布完整同口径排行且 `gpt-5-nano` 最低，则可确认
- 反证或冲突：已打开页面之间没有直接冲突，但缺少覆盖所有候选与价格模式的官方绝对排名
- 状态：当前未知
- 置信理由：官方页面能够确认模型和单项价格，却不足以放行原句的宽泛“最便宜”比较
- 下一步核验动作：先把“文本模型”和计价模式限定清楚，再对官方当前模型目录做完整同口径价格表

## C4 因为输入价低，所以任何人都能零成本使用

- 主张类型：因果主张、数字与比较
- 时效性：高
- 关键结论词与判定条件：“任何人”要求无账户、地区、资格或额度例外；“零成本”要求输入、输出及必要工具均为 0 美元，而不是价格较低
- 原始来源：[GPT-5 nano Model | OpenAI API](https://developers.openai.com/api/docs/models/gpt-5-nano)
- 来源层级：A2 主体自述
- 证据角色：主体自述
- 来源日期：页面未标注发布日期；访问核验于 2026-08-05
- 是否实际打开：是；成功打开，最终 URL 与链接一致
- 来源身份门：匹配
- 是否直接支持：否；页面给出非零输入价和非零输出价，并在 rate limits 表中写明 Free 为 Not supported
- 内容支持门：不支持
- 支持范围：官方 API 的常规定价与该模型的公开速率层；不排除某些用户可能另有促销、试用或合同额度，但这不能推出“任何人”
- 推断跨度：3；从“单项价格低”跳到“总成本为零”，再普遍化到“任何人”
- 行动适用门：不足以支持按零预算部署或承诺免费服务
- 可反驳观察：OpenAI 官方发布对所有人无条件开放、覆盖输入输出与必要工具的永久零价政策
- 反证或冲突：官方模型页显示输入 0.05 美元、输出 0.40 美元，且 Free 层不支持，直接冲突
- 状态：被反驳
- 置信理由：非零公开价格已经否定“零成本”，Free 层不支持又否定“任何人都能”的普遍化
- 下一步核验动作：查看目标账户的实际资格、地区、免费额度和账单设置，再计算该人的真实成本

## 当前未知

- 未定义“API 文本模型”的候选范围和“最便宜”的计价口径，因此不能确认全局绝对最低。
- 某个具体用户是否享有临时额度、促销或特殊合同，不能由公开价格页判断。
