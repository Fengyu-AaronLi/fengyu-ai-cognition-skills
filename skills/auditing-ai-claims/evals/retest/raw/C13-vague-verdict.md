# AI 主张审计

核验日期：2026-08-05

审计范围：拆分审计三项主张：公司自选 100 个问答中零次错误引用、Model Q 彻底解决幻觉、Model Q 可安全用于所有企业任务。题目没有提供公司报告的标题或 URL，因此我没有实际打开该报告；以下把“报告真实且确实如此记载”作为题设前提，审计它能支持多远。另已打开 NIST 的 AI RMF 1.0 与生成式 AI Profile，用于界定评测和安全判准，不把通用框架当作 Model Q 的认证。

快速结论：**不能据此确认。**即使完全接受公司报告，最多也只能写成：“在报告所述 Model Q 版本和配置下，公司自选的 100 个问答按其既定评分方法评测时，未观察到错误引用。”这既不等于没有其他类型的幻觉，也不等于在所有企业任务中安全。

## C1 公司自选的 100 个问答中没有出现错误引用

- 主张类型：产品能力与数字结果
- 时效性：高。模型版本、系统提示词、检索库、工具、采样参数和产品更新都可能改变结果
- 关键结论词与判定条件：“没有出现”必须绑定确切模型版本和配置、100 个原始问题、运行次数、测试日期、错误引用定义、评分规则、评分者及原始输出
- 原始来源：公司报告未提供标题或 URL，本轮无法实际打开
- 来源层级：若报告如题设所述，属于 A2 主体自述
- 证据角色：公司自测，不是独立验证或复现测试
- 来源日期：未知
- 是否实际打开：否；缺少可定位 URL
- 来源身份门：未知
- 是否直接支持：条件式支持更窄的测试观察，不支持外推
- 内容支持门：部分
- 支持范围：仅限报告中的特定 Model Q 版本和配置、公司自选的 100 个问答、既定的“错误引用”指标、评分程序和测试时间窗口
- 推断跨度：0，仅针对“这次测试记录了 0 次错误引用”；若外推到未测问题、其他错误类型或现实部署，则升为 3
- 行动适用门：不足以支持企业全面部署
- 可反驳观察：原始输出中存在一个被漏标的错误引用，或独立复现无法得到相同结果
- 反证或冲突：未取得报告原文、原始输出和独立复现，无法检查
- 状态：**无法核验**。题设可作为条件式前提，但不能替代实际打开来源
- 置信理由：报告身份与内容未能核对；即便报告无误，其来源角色仍只是公司自测
- 下一步核验动作：提供报告 URL、完整测试集、原始输出、评分说明和锁定的模型配置，让独立评测者盲审并复现

## C2 Model Q 已经彻底解决幻觉

- 主张类型：产品能力的普遍断言
- 时效性：高
- 关键结论词与判定条件：“彻底解决”至少必须预先固定：
  1. 模型版本、系统配置、检索与工具链
  2. 幻觉的错误类型，不只错误引用，还包括虚构事实、错误归属、与输入偏离、前后自相矛盾等
  3. 明确且有边界的任务分布、语言、长上下文、随机重复、边缘与对抗情形
  4. 评测和上线后的观察时间窗口
  5. 预先声明的失败条件。若坚持“彻底”这一绝对表述，在已界定范围内出现一个可复现的幻觉就应使其不成立
- 原始来源：[NIST AI 600-1 生成式 AI Profile](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf)，2024-07-26。NIST 将 confabulation 定义为自信呈现错误或虚假内容，也包含偏离输入或在同一上下文中自相矛盾；并明确建议避免从狭窄、非系统性评估外推能力
- 来源层级：A1 官方技术框架原文
- 证据角色：原始规范性指导，不是对 Model Q 的产品认证
- 是否实际打开：是；PDF 可访问，共 64 页
- 来源身份门：匹配 NIST AI 600-1，不匹配任何具体 Model Q 报告
- 是否直接支持：否。公司测试只覆盖“错误引用”这一子类型和 100 个自选问题
- 内容支持门：仅对更窄观察部分支持，对“彻底解决”不支持
- 支持范围：100 个自选问答、一次或未说明次数的测试、单一指标；任务代表性、随机性、版本稳定性和时间外推均未知
- 推断跨度：3。从一个公司自选小样本的单一指标跨到全部错误类型、全部输入和持续未来表现
- 行动适用门：不足以支持任何“无需约束即可使用”的行动
- 可反驳观察：在预先界定的适用范围内，独立测试发现一个可复现的虚构事实、错误归属、矛盾输出或错误引用。若范围仍是“所有输入”，有限样本只能增加信心，不能证明绝对不存在反例
- 反证或冲突：NIST 明确要求测试集贴近预期使用条件、记录泛化限制，并避免从狭窄评估外推；这与该普遍化推断冲突
- 状态：**部分支持**。只支持“这 100 个问答按该指标未观察到错误引用”，不支持“彻底解决幻觉”
- 置信理由：错误类型、任务分布、模型版本、时间窗口和失败条件均未被公司测试覆盖
- 下一步核验动作：由与开发团队独立的评测方，在锁定版本上使用隐藏的代表性测试集、跨域压力测试、对抗提示和多次随机复现，覆盖预先定义的全部幻觉类型，并公开方法、原始结果与不确定性

## C3 Model Q 可以安全用于所有企业任务

- 主张类型：产品安全与部署承诺
- 时效性：高
- 关键结论词与判定条件：“安全”不能由引用正确率单独定义。必须针对具体用途预先确定危害类别、受影响对象、严重度、组织和监管要求、可接受残余风险、人工监督、失效保护、停用与事件响应，并给出观察窗口和失败条件。“所有企业任务”还必须列出完整任务边界；否则没有可复现的总体判定。这里不存在可以替用户补上的万能安全阈值
- 原始来源：[NIST AI RMF 的风险与可信特征](https://airc.nist.gov/airmf-resources/airmf/3-sec-characteristics/)与 [AI RMF Core](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)，2023。框架要求按使用情境平衡有效可靠、安全、安保韧性、问责透明、隐私与公平等特征；评测应接近部署条件，残余风险不超过情境化风险容忍度，并能安全失效和持续监测
- 来源层级：A1 官方技术框架原文
- 证据角色：原始规范性指导，不是对 Model Q 的独立验证
- 是否实际打开：是；页面可访问
- 来源身份门：匹配 NIST AI RMF，不匹配 Model Q 的安全证明
- 是否直接支持：否
- 内容支持门：不支持
- 支持范围：公司报告只测错误引用，没有提供隐私泄露、网络安全、偏见、越权行动、有害输出、可靠性、人工监督、法规适配或安全失效证据
- 推断跨度：3。从一个准确性子指标跨到多维安全，再跨到所有企业领域和部署方式
- 行动适用门：不足以支持企业全面上线；医疗、法律、财务、安全或自动执行等高影响用途还需要各自的专业与法域审查
- 可反驳观察：任一声称覆盖的企业任务存在不可接受残余风险、无法安全失效、关键控制被绕过，或真实部署中的伤害与错误超出预先批准的风险容忍度
- 反证或冲突：没有 Model Q 的独立安全评估、红队结果、真实任务试点或上线监测数据
- 状态：**当前未知**。现有材料不能证明安全，也不能据“证据不足”反推其必然不安全
- 置信理由：安全所需的用途边界、危害清单、阈值、控制与部署证据全部缺失
- 下一步核验动作：逐项列出拟部署的企业用途，由独立人员做情境化威胁建模、红队和压力测试，再进行受控真实任务试点，验证人工复核、权限最小化、安全失效、事件响应与持续监测

## 两项结论共同成立的判准

“彻底解决幻觉”与“安全”是两个必须同时通过的门，而且必须针对**同一 Model Q 版本、同一系统配置、同一明确用途范围和同一时间窗口**：

1. 幻觉门：独立、代表性且包含压力与对抗情形的评测，覆盖预先定义的全部相关错误类型，并满足预先声明的失败条件。若坚持绝对的“彻底”，任何范围内可复现反例都使其失败；有限的 100 题不能证明无界输入空间中不存在反例。
2. 安全门：针对每个具体企业用途完成危害映射和领域适用评估，设定由风险所有者、专业标准或监管要求决定的情境化接受阈值，证明控制有效、残余风险可接受、系统能安全失效，并通过真实任务评估和持续监测。不能用一个凭空设定的数字覆盖所有领域。
3. 联合门：只有幻觉门和安全门都通过，才能对已界定的用途范围作有限结论。任一企业任务尚未评估、任一关键危害未覆盖，或任一门失败，都不能声称“可安全用于所有企业任务”。

当前证据只触及第一道门中的一个很窄子指标，因此联合结论不成立。

## 当前未知

- 具体报告、Model Q 版本与测试配置是什么
- 100 个问题如何选取，是否代表任何真实企业任务
- 是否测试了引用以外的幻觉类型、随机重复、长上下文和对抗输入
- Model Q 在隐私、安全、公平、越权操作及高影响任务中的表现
- 真实部署多长时间后仍能维持表现，以及版本更新后结论是否仍成立

## 最有效的下一步

1. 先让独立评测方取得锁定版本、完整公司测试材料和原始输出，做隐藏测试集复现与跨域压力测试。这能改变 C1 和 C2 的状态。
2. 再把“所有企业任务”改成一份具体用途清单，逐项完成危害评估、红队与受控真实任务试点。这能决定哪些用途可以在明确控制下获批，而不是给出无边界的“全部安全”承诺。
