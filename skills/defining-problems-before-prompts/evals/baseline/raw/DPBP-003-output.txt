我会把项目收窄成一个能 30 天 demo、能当月收钱的 B2B 工具：

**产品定位**

做一个「AI 需求定义与交付生成器」：用户输入一句模糊需求，例如“帮我做一个 AI 客服”“我想做知识库”“老板要一个自动化系统”，产品自动产出：

1. 问题定义
2. 用户场景
3. MVP 功能范围
4. 技术方案
5. 报价/排期
6. 验收标准
7. 可导出的 PRD / 项目提案 / 投资人 demo brief

核心卖点不是“又一个聊天机器人”，而是帮创业者、外包团队、咨询顾问、产品经理把模糊想法变成可执行方案。这个场景离钱近，用户愿意为省时间、减少返工、提高成交率付费。

**MVP 功能清单**

第一个月只做这些：

1. 登录与项目工作台
   邮箱登录、项目列表、创建新项目、历史版本。
2. AI 需求诊断流程
   用户输入项目想法，系统自动生成 6 个模块：目标用户、核心痛点、使用场景、付费理由、MVP 边界、风险假设。
3. 一键生成融资/demo 版本
   输出适合投资人看的 1 页产品叙事：市场切口、用户痛点、解决方案、商业模式、四周 demo 范围。
4. 一键生成开发交付版本
   输出 PRD、功能清单、技术架构、接口草案、验收标准、四周排期。
5. 模板库
   先内置 5 个高价值模板：AI SaaS、知识库、销售助手、内容工具、内部自动化工具。
6. 导出与分享
   PDF、Markdown、公开分享链接。
7. 付费墙
   免费生成 1 个项目；付费解锁完整导出、历史项目、多模板、深度诊断。

**技术栈**

前端：`Next.js + TypeScript + Tailwind CSS + shadcn/ui`
后端：`Next.js Server Actions / API Routes`
数据库：`Supabase Postgres`，Pro 版从 $25/月起，适合 MVP 阶段
认证：`Supabase Auth`
AI：`OpenAI Responses API`，主模型用 `gpt-5.6-luna` 控成本，关键生成用 `gpt-5.6-terra`
支付：`Stripe Checkout + Billing`，美国线上卡支付标准费率为 2.9% + 30¢
部署：`Vercel Pro`，$20/月起
文档导出：`react-pdf` 或服务端 HTML 转 PDF
埋点：`PostHog` 或 `Plausible`

公开价格参考：OpenAI 当前 API 页面显示 GPT-5.6 Luna 为 $1 输入 / $6 输出每百万 token，Terra 为 $2.5 输入 / $15 输出每百万 token；Vercel Pro 为 $20/月；Supabase Pro 为 $25/月；Stripe 标准线上支付为 2.9% + 30¢。
来源：[OpenAI API](https://openai.com/api/)、[Vercel Pricing](https://vercel.com/pricing)、[Supabase Pricing](https://supabase.com/pricing)、[Stripe Pricing](https://stripe.com/pricing)

**收费方案**

免费版：1 个项目，基础诊断，不能导出 PDF。

个人版：`$19/月`
每月 20 个项目，PDF/Markdown 导出，5 个模板。

Pro 版：`$49/月`
每月 100 个项目，深度诊断，公开分享链接，品牌水印移除。

团队版：`$149/月`
5 个成员，团队项目库，协作评论，自定义模板。

一次性付费：`$29/份`
不想订阅的用户可以买单份完整报告。这个对早期转化很重要。

**四周开发排期**

第 1 周：产品骨架和核心 AI 流程
完成登录、项目创建、基础工作台、AI 需求诊断 prompt chain、结果结构化 JSON 输出。目标是能从一句话生成完整项目诊断。

第 2 周：报告生成和模板库
完成 5 个模板、PRD 输出、融资 brief 输出、技术方案输出、Markdown 编辑预览。目标是 demo 时能展示“输入一句话到完整方案”。

第 3 周：导出、分享、付费
接入 Stripe，完成免费额度、订阅权限、PDF 导出、分享页面、历史项目。目标是能真实收钱。

第 4 周：融资 demo 打磨和上线
完成视觉接入、首页、示例项目、埋点、错误监控、成本限制、提示词缓存、3 个高质量 demo case。目标是投资人看到一个能注册、能生成、能付费、能分享的产品。

**融资叙事**

一句话：
“我们做的是 AI 时代的需求定义层，把模糊想法变成可执行、可报价、可交付的项目方案。”

为什么现在：
AI 生成能力已经足够强，但大多数人不会定义问题，导致提示词、需求、外包、开发全部返工。

为什么能赚钱：
目标用户不是泛娱乐用户，而是创业者、咨询顾问、外包团队、产品经理。他们每次节省的是数小时沟通成本和数千到数万元返工成本，$19 到 $149/月定价成立。

我建议就按这个方向做，不要做泛 AI 助手。泛 AI 助手一个月只能做出壳，这个方向一个月能做出真实闭环：注册、生成、导出、分享、付费。
