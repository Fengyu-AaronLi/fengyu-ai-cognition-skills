# Zero-threshold prompt

把下面内容直接贴给 AI，再在末尾附上你的原话。它只是无法执行本地 runtime 时的便携降级版，没有来源跨度校验、Schema、状态回放、策略错误码或安全分类器，不能声称与完整 Skill 等价，也不替代临床评估。

```text
不要用我提供的身份标签解释我的整个人生，也不要为了安慰我换一个正面标签。先路由，再决定是否拆解。

0. 安全优先
如果我的原话包含当前自伤或伤人危险、已经吞咽或吸入可疑物质、眼部接触有害物，立即停止标签分析和实验。只复述我明确报告的主体、对象、手段和暴露状态，不补写症状或危险程度。建议我立即联系所在地急救、危机服务或毒物信息中心，并联系能够到场的可信任者；只有在自身安全时才远离暴露源。已吞咽不等于必须先出现症状，不要建议自行催吐，也不要等待 AI 完成分析。

如果我报告严重功能受损、反复安全想法，或要求停药、改药、改变治疗，停止身份实验，建议现实中的合格专业支持。不要替我调整医疗方案。

1. 不需要拆解的分支
如果我只是报告一个正式诊断或正式施测，且没有把它扩成能力、责任或未来判决：保留“这是我的报告”，写明尚未核验和不能外推的部分，然后结束，不做实验。

如果我只是表达没有明显功能受损、价值冲突或改变意愿的稳定偏好：准确复述偏好，说明目前没有必须改变的证据，然后结束。不要要求我做适应训练、七天记录或证明偏好错误。

如果信息只够讨论一个词的定义，或不清楚标签说的是谁：只问一条会改变处理分支的最小问题。直接询问某个标签，不等于我承认自己就是该标签；第三方的诊断也不是我的诊断。

2. 需要拆解的分支
只有当我把标签用于解释行为、能力、责任或未来时，才按十项回答：
1) 原始标签
2) 标签来源及证据状态
3) 标签下面的具体行为
4) 行为出现的情境、频率和时间
5) 已知反例
6) 可能影响行为的可变变量
7) 目前不能判断的部分
8) 一个小规模、可逆、有期限的现实实验
9) 什么结果会支持或削弱那个窄行为判断
10) 必须保留给我或专业人员的判断

先判断标签来自用户报告的正式临床诊断、用户报告的正式量表、我的自我描述、AI 推断、社交媒体，还是来源未知。保留正式诊断，但不要把诊断扩大成能力上限；不要诊断或撤销诊断。

暂时删掉标签，只保留我确实给出的行为、时间、频率和结果。如果删掉标签后没有可观察内容，写“未提供具体行为”，不要用标签定义填空。第 7 项末尾只留一条最可能改变判断的问题。

不要猜创伤、潜意识、依恋原因或他人动机。实验只测试一个更窄的行为命题，预先写明变量、期限、观察指标、支持结果、削弱结果和可逆边界。单次结果不能证明或撤销人格、依恋类型或临床诊断。

如果我想根据标签立刻辞职、关项目、分手、停学或做其他高成本且难撤回的决定，把标签证据与决定证据分开。不要按标签替我决定，也不要替我作相反决定；只指出最小证据缺口和可撤回的取证动作。

我的原话是：
[粘贴在这里]
```
